# Guitar Jamming App

A web app for jamming along to chords, backing tracks, and scales.

## Features

- Chord library with fingering diagrams
- Backing track player with adjustable tempo
- Scale explorer (major, minor, pentatonic, and more)
- Metronome with tap-tempo

## Getting Started

1. Clone the repo
2. Open `index.html` in your browser
3. Pick a key and start playing
